# 百度网盘分享下载助手（实验版）

1. 在 Tampermonkey 中新建脚本，将 `百度网盘分享下载助手.user.js` 的全部内容粘贴进去并保存。
2. 打开 [VU13P 板资料分享](https://pan.baidu.com/s/1xA1HnSksKyQ0bX3WJEoDdA)，如需要提取码，尝试 `7nqi`（原始文本中有空格，请以分享者提供的准确提取码为准），并按百度网盘提示登录。
3. 打开文件夹、勾选文件，点击右下角“分享下载助手”，再点击“读取已选文件”或“尝试获取下载链接”。
4. 获得链接后可在浏览器打开或复制给下载管理器。链接可能绑定登录状态或很快过期，下载管理器不一定可以使用。不要把链接发给不可信的人。

本脚本只向当前百度网盘站点请求，不主动读取或向第三方发送 BDUSS，不要求第三方 OAuth 授权，也不使用远程代码。浏览器会按照网站的正常登录机制向百度附带 Cookie。分享接口及页面内部数据结构可能已经变化，失败时会显示接口错误；没有承诺绕过服务端限速，也未在实际登录页面上验证。账号权限、服务端策略和文件大小都可能影响结果。0.4.0 版在普通接口返回字符串列表时，最多额外尝试一次备用参数；不能保证拿到链接。

你提供的原始代码中，较新的下载助手在分享页要求先保存到个人网盘，再通过 OAuth 与接口获取个人文件的链接。原文还包含调用 `/api/sharedownload` 的旧版分享流程；这里仅按这一思路做兼容尝试，接口是否仍有效必须实测。请勿把网盘登录 Cookie、访问令牌或完整下载链接发给别人。
